How It Works

The AI Assistant runs locally or connects to Anthropic's Claude. It answers only about your own records — never about colleagues' data. When you upload company policy PDFs, it can cite them directly in answers.

Frequently Asked Questions

Do I need to install Java?

No. The installer bundles Java 17 runtime. Users need nothing pre-installed.

Is my data safe?

Yes. Data is stored locally in an encrypted H2 database file. Nothing is sent to the cloud unless you explicitly use the AI assistant with external models.

What database does it use?

AXVON HRMS uses H2 Embedded Database stored locally. No MySQL, PostgreSQL, or external database setup required.

Can I install on Mac or Linux?

Currently AXVON HRMS is designed for Windows. The Electron framework makes cross-platform builds possible, but the current release targets Windows only.

Is there an AI assistant?

Yes! AXVON HRMS includes an AI HR Assistant that can answer questions about your leave, payroll, and company policies. It works locally with Ollama or connects to Anthropic's Claude.
